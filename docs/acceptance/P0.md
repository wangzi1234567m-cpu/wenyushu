## 手工验证步骤

1. 安装并启动 Docker Desktop Linux containers，在仓库根目录执行 `python scripts/dev.py up`；预期 web/api/worker/postgres 就绪，migrate 正常退出。失败时保留日志，不能标 PASS。
2. 访问 http://localhost:3000，预期首页显示三类功能“准备中”，底部“匿名访问已就绪”，无真实推荐/聊天操作。
3. 刷新页面，在浏览器 Network 确认 bootstrap 201；Cookie 的值不变，CSRF token 变化，Secure/HttpOnly/SameSite=Lax 存在。
4. 新开独立浏览器上下文，匿名 Cookie 与第一个不同；不要将 Cookie 或 token 复制到验收文档。
5. DevTools 在当前同源页面发送 `fetch('/api/v1/auth/anonymous-session',{method:'DELETE'})`，预期 422 统一错误；带错误 X-CSRF-Token 则 403。正常携带当前 bootstrap 的 CSRF 应返回 200 并清除 Cookie。
6. 检查 `/api/v1/health/live`、`/api/v1/health/ready` 均 200；停止数据库后 live 仍 200，ready 为 503；恢复数据库后 ready 恢复。
7. 切换 390px 与 1440px，主内容无横向溢出；阻断 bootstrap 请求后可见重新连接按钮，恢复网络后可重试。
8. `python scripts/dev.py down` 后再次 up，原数据库卷保留；不运行 down -v。

截图由 Playwright 输出至本地忽略目录 `web/test-results/home-desktop.png` 与 `home-mobile.png`，已目视检查布局；生成缓存和测试 Cookie 不提交。
