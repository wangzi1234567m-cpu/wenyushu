## 人工步骤（操作 → 预期）

1. Docker 引擎就绪后 `python scripts/dev.py up`，访问 http://localhost:3000；每日卡片显示固定题目，找书与思辨独立入口仍标准备中。
2. 点击开始探索，选立场，填可选补充，继续；不同立场进入相应追问，最多3步，偏好可跳过。
3. 中途刷新，应显示已提交的可读选择和补充原文，继续当前步骤；不显示服务器内部 step/option ID。
4. 完成后应提示已整理阅读方向；尚未点击找书时不创建任务。点击后看到明确标识的固定样例书单、介绍、对应理由和真实书目来源。
5. 刷新已出书单页面，应恢复同一结果；修改第二步，确认恢复有效前缀，再选择不同关注方向，应得到新意图/书单，旧探索保持不变。
6. 浏览器阻断答案请求，输入保留并显示错误；恢复网络后重试可继续。改答前缀重放失败后刷新，也可恢复重放。
7. 用独立浏览器身份请求另一身份探索/书单，应404。无/错误CSRF写请求被拒；补充301字符从API提交应422。
8. 在390px和1440px检查选择、输入、改答、书单和来源链接；无阻断交互的横向溢出。

Playwright 截图保存到忽略目录 `web/test-results/daily-desktop.png` / `daily-mobile.png`；不提交测试缓存或用户私密内容。
