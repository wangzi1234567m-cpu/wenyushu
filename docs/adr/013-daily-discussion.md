# ADR-013：每日一问从选择理由进入持续讨论

- 状态：用户于2026-10-27明确修订交互并选择接入真实DeepSeek，批准将必要的通用对话能力前移；不接入书籍检索。
- 原因可多选、推荐预留页按澄清问题的建议默认实施；密钥由用户本机填写。

## 决策

每日一问变为：支持哪一方 → 认同哪些理由及可选补充 → 与AI持续探讨。取消新版本中的阅读偏好步骤与内嵌样例书单。旁栏“根据讨论推荐书”导航到独立预留页，保留返回原讨论的入口，不创建推荐/Handoff任务。

探索答案保持兼容的 option_id，增加可选 option_ids（1—6个、唯一、规范排序）。只有标记 multiple 的步骤允许多选，所选分支必须有相同后继；旧版本单选不变。新增 content.exploration_answers.option_ids JSONB。

通过已存在的 conversation(kind=discussion) API提供持久化、SSE、幂等和压缩；ConversationCreate增加可选 exploration_id。discussion应用协调器经探索快照端口获取当前身份已完成探索，再调用通用会话端口创建会话。discussion.contexts 只保存固定题目/初始立场/理由，不复制聊天记录；按actor+exploration幂等。

ConversationRuntime只负责消息序号、单轮生成、持久化、流式、最近历史和摘要。DiscussionPolicy提供初始背景及思辨规则，不依赖reading/catalog/handoff。聊天不会创建阅读意图或推荐任务。

DeepSeek通过服务端HTTP适配LLMPort，Key仅SecretStr/.env或服务端环境读取。缺Key明确失败，不自动冒充Mock。流只发送content，正常stop结束后才完成；reasoning不透传。上下文按保守预算压缩旧的已完成轮次，摘要保留观点变化与条件；失败保留原始消息和旧摘要，允许重试。

本次公开已有conversation端点，保持原有消息字段和SSE事件；补充只读provider_mode供界面标识Mock。补全统一错误契约原先遗漏的404声明，资源不存在与越权继续返回相同404，不改变拒绝行为。同步SAD、阶段说明、OpenAPI、增量迁移、DTO和测试，不修改已发布的0001/0002。

## 来源与范围

观点来源为2024-07-24“数统院辩论队友谊赛”的公开文字实录 https://debatetimer.cn/record/66a0f2c5a92f8e067c57d797 。只从标为开篇陈词/自由辩论的原文整理，不使用页面另列的AI总结冒充原话；选项为编辑改写，无逐字引用或辩手归因。此来源为用户上传实录，未冒称节目官方核验。另一个B站候选视频因412无法核验，不作为论点依据。

不实施真实找书、实时搜索或P4推荐联动，不把本次前移视为P3整体已验收。后续P3仍需补齐质量、安全与长会话验收。用户已配置服务端Key；2026-10-27真实适配调用及浏览器两轮连续对话、刷新恢复均已实际验证，未记录密钥或用户真实私密输入。
